SongLines

Мод для Minecraft, добавляющий музыкальный плеер и синхронизированные субтитры прямо в игровой мир.

Поддерживает локальную музыку и воспроизведение через телефон с помощью SongLinesBridge.

- Настройка внешнего вида субтитров и музыкальной карточки.
- Папки для сортировки музыки.
- Избранное, перемешивание и повтор воспроизведения.
- Поддержка управления музыкой с телефона через SongLinesBridge.

Режимы субтитров

Режим| Описание
Bottom| Субтитры над панелью быстрого доступа
World| Плавающие строки непосредственно в игровом мире
Entity| Строки, закреплённые в определённой точке мира
Panel| Несколько строк в боковой панели
Off| Субтитры выключены

Музыкальный плеер

SongLines может самостоятельно воспроизводить музыку из локальной библиотеки.

Поддерживаются:

- MP3 и OGG;
- папки с музыкой;
- очередь воспроизведения;
- перемешивание треков;
- повтор одного трека или всей очереди;
- избранные композиции;
- управление громкостью.

Тексты песен загружаются из локальных LRC-файлов или находятся автоматически через LRCLIB. Найденные тексты сохраняются в кэше.

SongLinesBridge

SongLinesBridge — отдельное Android-приложение для подключения музыкального плеера телефона к Minecraft.

Оно получает информацию о воспроизводимой композиции через Android MediaSession и передаёт её моду.

Поддерживается:

- название композиции и исполнитель;
- название альбома;
- позиция и продолжительность воспроизведения;
- обложка альбома;
- состояние воспроизведения;
- переключение треков;
- пауза и возобновление.

"SongLinesBridge — репозиторий и загрузки" (https://github.com/TR0IKA/SongLinesBridge)

Установка

Требования:

- Minecraft 1.21.11
- Fabric Loader 0.18.0 или новее
- Fabric API
- Java 21 или новее

1. Установите Fabric для Minecraft 1.21.11.
2. Установите Fabric API.
3. Скачайте SongLines.
4. Переместите ".jar"-файл в папку "mods".
5. Запустите Minecraft.

Локальная музыка

После первого запуска мода появится папка:

"/.minecraft/songlines/music/"

Добавьте туда свои MP3 или OGG-файлы.

Можно создавать отдельные папки для альбомов и плейлистов.

Для локальных текстов используйте ".lrc" с таким же именем, как у аудиофайла.

Например:

songlines/
└── music/
    ├── Album/
    │   ├── track.mp3
    │   └── track.lrc
    └── Another/
        └── song.ogg

Управление

Стандартные клавиши:

Действие| Клавиша
Открыть меню| M
Предыдущий трек| [
Следующий трек| ]
Пауза / воспроизведение| \
Добавить в избранное| '
Переключить режим субтитров| ;

Все клавиши можно переназначить в настройках управления Minecraft, категория SongLines.

Настройки

Конфигурация находится здесь:

"/.minecraft/songlines/config.json"

Здесь хранятся настройки воспроизведения, субтитров, анимаций, цветов, обложек и подключения моста.
